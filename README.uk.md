# Shoutout Desk OBS

**Українська** · [Русский](README.ru.md) · [English](README.md)

Локальний плагін автовідміток Twitch зі зручною темною док-панеллю OBS. Додайте стримерів до списку: перше повідомлення людини після таймауту поставить офіційний шотаут у чергу. Streamer.bot, акаунт на нашому сайті та режим модератора не потрібні.

## Встановлення

Вимоги: Windows 10/11 x64, OBS 32.x із Qt 6.8 або новішим, власний акаунт стримера Twitch.

1. Завантажте Windows x64 ZIP зі сторінки [Releases](https://github.com/foolka/shoutout-desk-obs/releases) і розпакуйте **весь архів**.
2. Повністю закрийте OBS. Запустіть `Install.cmd`; якщо Windows забороняє запис до ProgramData, запустіть від адміністратора.
3. Відкрийте OBS → **Док-панелі → Shoutout Desk** і закріпіть панель у зручному місці.

Інсталятор перевіряє SHA-256 та змінює лише `C:\ProgramData\obs-studio\plugins\shoutout-desk-obs`. Сцени, джерела, налаштування трансляції та бібліотеки OBS не замінюються. Інсталятор цієї тестової версії призначений для звичайного встановлення OBS, не для portable-режиму.

## Налаштування

Кнопка з іконкою панелі біля перепідключення закріплює плагін праворуч в OBS, навіть коли перетягування заблоковане. Для ручного перетягування вимкніть блокування док-панелей у меню OBS. Плагін не розблоковує інші панелі.

1. **Налаштування → Увійти через Twitch**. На офіційній сторінці Twitch введіть код із панелі та дозвольте доступ від власного акаунта стримера.
2. Додайте ніки або посилання на вкладці **Люди**, налаштуйте таймаут від 1 до 168 годин і ввімкніть автовідмітки.
3. Поки OBS відкрито, плагін слухає чат. Відмітки надсилаються лише коли Twitch підтверджує прямий ефір. Приховування панелі не зупиняє роботу, закриття OBS зупиняє.

У публічній збірці спільний Public Client ID вже вказаний. Користувачу не потрібно створювати застосунок розробника або вводити Client Secret. Розробникам форків потрібен власний Client ID: [Developer Console](https://dev.twitch.tv/console/apps), тип **Public**, категорія **Chat Bot**, Redirect URL `http://localhost` (вхід за кодом його не використовує), файл `data/twitch-client.json`.

Запитуються лише `user:read:chat` та `moderator:manage:shoutouts`. Другу назву встановив Twitch, вона потрібна також власнику каналу. У плагіні немає вибору чужого каналу чи режиму модератора. Ключ трансляції, пошта, підписки та фінансові дані не запитуються.

## Оновлення Без Втрати Даних

**Скидання після закриття OBS** за замовчуванням вимкнене. Наступний запуск скине таймаути плагіна лише після перерви понад 60 хвилин. Час роботи OBS не вважається перервою. Після аварійного завершення використовується остання позначка роботи із запасом 30 секунд.

**Скинути всі таймаути** запитує підтвердження з відповіддю «Ні» за замовчуванням. Обидва варіанти зберігають список та історію, скасовують чергу й чекають нових повідомлень у чаті. Обмеження Twitch та загальний захисний інтервал залишаються. Натискання не запускає трансляцію чи шотаути.

У налаштуваннях натисніть **Перевірити оновлення**. Завантажте новий повний архів, розпакуйте, закрийте OBS і запустіть новий `Install.cmd`. **Лише DLL недостатньо.**

- База, налаштування та захищений вхід зберігаються окремо: `%LOCALAPPDATA%\Shoutout Desk OBS`.
- Під час першого запуску нової версії до відкриття бази створюється узгоджена резервна копія SQLite з урахуванням WAL та копія зашифрованого входу в `backups`. Помилка копіювання зупиняє запуск.
- Попередні файли плагіна зберігаються в `%PROGRAMDATA%\ShoutoutDeskOBS-install-backups`. Для відкату через зміну схеми бази потрібна відповідна копія даних.
- **Імпорт / Експорт** переносить список, історію та таймаути без токенів. Можна імпортувати `shoutouts.sqlite` старого Shoutout Desk того самого акаунта. Спочатку закрийте старий застосунок. Імпорт створює бекап, об’єднує дані та залишає автовідмітки призупиненими.
- Оновлення не встановлюються автоматично. Перевірка звертається до GitHub лише після натискання кнопки.

## Безпека Та Обмеження

Токени Twitch захищені Windows DPAPI для поточного користувача Windows і не передаються на наш сервер. Немає телеметрії та відкритого локального мережевого порту. Плагін сам запускає комплектний обробник Node.js через закриті канали процесу та завершує його разом з OBS. Текст повідомлень чату не зберігається. Список та історія SQLite не зашифровані: захищайте профіль Windows і приватні резервні копії.

**На одному каналі має працювати один екземпляр автовідміток.** Зупиніть застосунок чи хмарну версію перед увімкненням плагіна. Враховуються офіційні відмітки інших ботів, але за втрати подій чи одночасного надсилання стовідсотковий захист від повторів неможливий. Звичайне посилання від бота не вважається офіційним шотаутом.

Між відмітками витримується 125 секунд, особистий таймаут зберігається після перезапуску. Старі очікувані запити скасовуються; запит із невідомим результатом автоматично не повторюється. Вихід видаляє поточну локальну авторизацію. Щоб відкликати всі копії доступу, включно з бекапами, від’єднайте застосунок у [Підключеннях Twitch](https://www.twitch.tv/settings/connections).

Архіви поки не підписані сертифікатом Windows. SHA-256 захищає від пошкодження, але не підтверджує автора. Завантажуйте лише з цього репозиторію. Перший випуск попередній: вхід і реальний шотаут на активному каналі потребують окремої перевірки, автотести трансляцію не запускають.
