# Shoutout Desk OBS

**Українська** · [Русский](README.ru.md) · [English](README.md)

Локальний плагін автовідміток Twitch зі зручною темною док-панеллю OBS. Додайте стримерів до списку: перше повідомлення людини після таймауту поставить офіційний шотаут у чергу.

## Встановлення

Вимоги: Windows 10/11 x64, OBS 32.x із Qt 6.8 або новішим, власний акаунт стримера Twitch.

1. Завантажте `shoutout-desk-obs-ВЕРСІЯ-windows-x64-setup.exe` зі сторінки [Releases](https://github.com/foolka/shoutout-desk-obs/releases).
2. Повністю закрийте OBS та запустіть EXE. Виберіть українську, російську або англійську мову, підтвердьте запит прав адміністратора, перевірте знайдену папку OBS та натисніть «Установити».
3. Відкрийте OBS → **Док-панелі → Shoutout Desk** і закріпіть панель у зручному місці.

EXE містить усі залежності плагіна: установлювати Node.js, Streamer.bot чи інструменти розробника не потрібно. Майстер перевіряє версії OBS/Qt й не дозволяє встановлення або видалення, поки працює OBS. Він не закриває та не запускає OBS, не вмикає трансляцію й не перезавантажує комп'ютер. Файли встановлюються лише в `C:\ProgramData\obs-studio\plugins\shoutout-desk-obs`, у Windows з'являється пункт видалення. Сцени, джерела, налаштування трансляції та бібліотеки OBS не замінюються. Portable-режим не підтримується. Вхід Twitch виконується окремо в панелі OBS, не в інсталяторі.

Повний ZIP з `Install.cmd` залишається альтернативою: розпакуйте весь архів, закрийте OBS і запустіть `Install.cmd` (за потреби від адміністратора). Він перевіряє SHA-256 файлів перед установленням.

## Налаштування

Кнопка біля перепідключення перемикається між **Відкріпити від OBS** (стрілка) та **Закріпити в OBS** (іконка панелі). Вона працює навіть при заблокованому перетягуванні й повертає панель у попередню область або праворуч, якщо область ще не задана. Для ручного перетягування вимкніть блокування док-панелей у меню OBS. Плагін не розблоковує інші панелі.

1. **Налаштування → Увійти через Twitch**. На офіційній сторінці Twitch введіть код із панелі та дозвольте доступ від власного акаунта стримера.
2. Додайте ніки або посилання на вкладці **Люди** та налаштуйте таймаут від 1 до 168 годин. Автовідмітки вмикаються під час кожного запуску OBS і після нового входу. Зняття прапорця **Увімкнено** призупиняє їх до наступного запуску; таймаути при цьому не скидаються.
3. Поки OBS відкрито, плагін слухає чат. Відмітки надсилаються лише коли Twitch підтверджує прямий ефір. Приховування панелі не зупиняє роботу, закриття OBS зупиняє.

У публічній збірці спільний Public Client ID вже вказаний. Користувачу не потрібно створювати застосунок розробника або вводити Client Secret. Розробникам форків потрібен власний Client ID: [Developer Console](https://dev.twitch.tv/console/apps), тип **Public**, категорія **Chat Bot**, Redirect URL `http://localhost` (вхід за кодом його не використовує), файл `data/twitch-client.json`.

Запитуються лише `user:read:chat` та `moderator:manage:shoutouts`. Другу назву встановив Twitch, вона потрібна також власнику каналу. У плагіні немає вибору чужого каналу чи режиму модератора. Ключ трансляції, пошта, підписки та фінансові дані не запитуються.

## Оновлення Без Втрати Даних

**Скидання після закриття OBS** за замовчуванням вимкнене. Наступний запуск скине таймаути плагіна лише після перерви понад 60 хвилин. Час роботи OBS не вважається перервою. Після аварійного завершення використовується остання позначка роботи із запасом 30 секунд.

**Скинути всі таймаути** запитує підтвердження з відповіддю «Ні» за замовчуванням. Обидва варіанти зберігають список та історію, скасовують чергу й чекають нових повідомлень у чаті. Обмеження Twitch та загальний захисний інтервал залишаються. Натискання не запускає трансляцію чи шотаути.

У налаштуваннях натисніть **Перевірити оновлення**. Завантажте новий EXE, закрийте OBS та встановіть поверх попередньої версії. Заздалегідь видаляти плагін не потрібно. ZIP також залишається доступним. **Лише DLL недостатньо.**

- База, налаштування та захищений вхід зберігаються окремо: `%LOCALAPPDATA%\Shoutout Desk OBS`.
- Під час першого запуску нової версії до відкриття бази створюється узгоджена резервна копія SQLite з урахуванням WAL та копія зашифрованого входу в `backups`. Помилка копіювання зупиняє запуск.
- ZIP-інсталятор зберігає попередні файли плагіна в `%PROGRAMDATA%\ShoutoutDeskOBS-install-backups`; EXE використовує звичайний механізм установлення та видалення Windows. Для відкату через зміну схеми бази потрібна відповідна копія даних.
- Для видалення EXE-інсталяції закрийте OBS та видаліть **Shoutout Desk OBS** через перелік установлених застосунків Windows. Особисті дані, зокрема збережений вхід, залишаються для повторного встановлення. Щоб не залишати активний токен, спочатку вийдіть з акаунта у плагіні; для відкликання доступу з резервних копій використовуйте підключення Twitch.
- **Імпорт / Експорт** переносить список, історію та таймаути без токенів, зокрема записи, раніше перенесені з Voice. Можна імпортувати `shoutouts.sqlite` старого Shoutout Desk того самого акаунта. Спочатку закрийте старий застосунок. Імпорт створює бекап, об’єднує дані та призупиняє автовідмітки до ручного ввімкнення або перезапуску OBS.
- Оновлення не встановлюються автоматично. Перевірка звертається до GitHub лише після натискання кнопки.

## Безпека Та Обмеження

Токени Twitch захищені Windows DPAPI для поточного користувача Windows і не передаються на наш сервер. Немає телеметрії та відкритого локального мережевого порту. Плагін сам запускає комплектний обробник Node.js через закриті канали процесу та завершує його разом з OBS. Текст повідомлень чату не зберігається. Список та історія SQLite не зашифровані: захищайте профіль Windows і приватні резервні копії.

**На одному каналі має працювати один екземпляр автовідміток.** Зупиніть застосунок чи хмарну версію перед увімкненням плагіна. Враховуються офіційні відмітки інших ботів, але за втрати подій чи одночасного надсилання стовідсотковий захист від повторів неможливий. Звичайне посилання від бота не вважається офіційним шотаутом.

Між відмітками витримується 125 секунд, особистий таймаут зберігається після перезапуску. Старі очікувані запити скасовуються; запит із невідомим результатом автоматично не повторюється. Вихід видаляє поточну локальну авторизацію. Щоб відкликати всі копії доступу, включно з бекапами, від’єднайте застосунок у [Підключеннях Twitch](https://www.twitch.tv/settings/connections).

EXE та архіви поки не підписані сертифікатом Windows: можливе попередження про невідомого видавця. SHA-256 захищає від пошкодження, але не підтверджує автора. Завантажуйте лише з цього репозиторію. Перший випуск попередній: вхід і реальний шотаут на активному каналі потребують окремої перевірки, автотести трансляцію не запускають.
